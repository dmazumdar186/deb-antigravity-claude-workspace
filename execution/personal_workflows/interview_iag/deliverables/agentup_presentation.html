0504 · Architecture
▲ AgentUp

Three lanes: browser · edge Function · LLM chain.

Static islands where possible, one Pages Function where it isn't, and a multi-provider fallback so no single upstream can kill the demo.

1. Browser
  • Astro islands (client:load) with React
  • Web Speech API — STT + chunked TTS
  • localStorage cases · sessions · streak
  • Client-side PII redaction (Aadhaar / PAN / mobile / UPI / cards)
  • Telemetry store · Dev HUD (Ctrl+`)
2. Cloudflare Pages Function
  • Hides ANTHROPIC_API_KEY + GEMINI_API_KEY
  • Origin allowlist w/ wildcard subdomain
  • Payload cap — 32KB → typed 413
  • KV rate limit — 500 calls / IP / day
  • Streaming SSE proxy (Anthropic → client)
3. LLM chain
  • Anthropic Sonnet 4.6 · primary
  • Gemini 2.5-flash-lite · fallback #1
  • Gemini 2.5-flash · fallback #2
  • Auto-swaps on credit-too-low 400 · retries 503/429
  • Streaming: SSE deltas · non-streaming: JSON
Browser ──▶ fetch("/api/claude") ──▶ Anthropic ◇ Gemini (fallback)

08★2 · Streaming + chunked TTS
▲ AgentUp

Time-to-first-audio drops 4×. On Call it stops feeling like a batch response and starts feeling like a call.

Before · batch response

~2000ms
0msagent sends
……waiting for full LLM response
2000whole customer reply appears · TTS speaks all at once

After · SSE + chunked TTS

~500ms
0msagent sends
400first token renders in bubble
500first phrase speaks · rest streams in
1800full reply done · TTS still finishing
Server proxies Anthropic's stream: true SSE. Client's ChunkedSpeaker matches phrase boundaries (. ? ! ,) and hands each to SpeechSynthesisUtterance. Force-flushes on soft-max (140 chars) so we never wait forever for a comma. 7 unit tests cover the buffering state machine.
