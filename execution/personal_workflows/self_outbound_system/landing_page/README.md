# debanjanm.com - landing page

One-page personal-brand site for `debanjanm.com`. Credibility anchor for
the self-outbound pipeline (cold email from `debanjan@debanjanm.com`).

Astro + Tailwind + Cloudflare Pages. Near-zero JS, static output.

## Quick deploy

```bash
cd execution/personal_workflows/self_outbound_system/landing_page
npm install
npm run build
npx wrangler pages deploy dist --project-name=debanjanm
```

First time: `wrangler login` then run the deploy command. Wrangler will
prompt to create the Pages project on first push.

## Local dev

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # dist/
npm run preview  # serves dist/
```

## Placeholders operator must fill before flipping DNS

Search the codebase for `TO_FILL` to find every one:

| Where | What |
|---|---|
| `src/components/Hero.astro` + `public/assets/portrait.jpg` | Portrait image (Hero uses graceful fallback if missing) |
| `src/components/Proof.astro` | 3 case studies - company / problem / outcome / stack tags |
| `src/components/WhyMe.astro` | Ex-companies string |
| `src/components/Footer.astro` | Postal address + SIRET |
| `src/pages/legal/lia.astro` | Postal address (same value) |

The postal address is legally required per `../legal/lia.md` (GDPR
LIA basis for cold outreach). It must be the same real address across the
footer, the LIA page, and the Instantly email footer template.

## Routing behaviour

- `/` - landing page
- `/meet`, `/book`, `/call` - `public/_redirects` sends 302 to Cal.com
- `/meet` (Astro page) - fallback if `_redirects` does not fire; meta-refresh + JS redirect
- `/legal/lia` - LIA document
- `/sitemap-index.xml` - generated by `@astrojs/sitemap`

Cal.com URL (public, safe to hardcode): `https://cal.com/debanjan-mazumdar-ben5rd/30min?utm_source=outbound&utm_campaign=debanjanm-outbound&utm_medium=email`

To rotate UTM params: edit in three places - `_redirects`, `Hero.astro`,
`TopNav.astro`, `BookingCTA.astro`, `meet.astro`. Grep for `utm_campaign`.

## Adding or editing case studies

Edit the `cases` array at the top of `src/components/Proof.astro`. Fields:
`company`, `problem`, `outcome`, `stack`. Names may be anonymised.

## Sitemap

Generated automatically by `@astrojs/sitemap` on `npm run build`. Output:
`dist/sitemap-index.xml` and `dist/sitemap-0.xml`. Referenced from
`public/robots.txt`.

## Design system

- Framework: Astro 5 + Tailwind 3
- Fonts: Bricolage Grotesque (body) + Newsreader (headers), Google Fonts
- Palette: paper / ink / warm amber accent (`tailwind.config.mjs`)
- No JS beyond meta-refresh fallback on `/meet`

## i18n

EN only for now. FR variant is Phase 2 nice-to-have - if the outbound
mostly hits FR-speaking prospects, add `/fr/` under
`src/pages/fr/index.astro` and split copy into a shared JSON.

## Front-door synthetic (per workspace rule)

Once deployed, wire a Cloudflare Cron / UptimeRobot probe that hits `/`,
`/meet`, and `/legal/lia` every 15 minutes and asserts:
- `/` returns 200 with `Debanjan Mazumdar` in the HTML
- `/meet` returns 302 to a `cal.com` host
- `/legal/lia` returns 200 with `Legitimate Interest Assessment`

Fails on any three consecutive misses. See `~/.claude/rules/front-door-synthetic.md`.

## What is deliberately not here

- No analytics / tracking pixels - GDPR-adjacent, and the outbound
  pipeline is the only funnel that matters.
- No blog or CMS - site is a credibility snapshot, not a publishing target.
- No contact form - a Cal.com booking is the only conversion.
- No newsletter opt-in - the outbound is the acquisition channel.
