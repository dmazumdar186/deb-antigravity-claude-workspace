# VPS scope: always-on box for the 7 self-hosted tools (2026-11-09)

## Why
Cloud sessions (Claude Code on the web) can run Docker, but containers there have no usable internet
(TLS intercepted, proxy only on the host's loopback), the disk is ~27 GB, and everything is wiped when
the session ends. Measured in session 2026-11-09: see `.claude/notes/general.md` `[cloud] docker services`.

## Sizing (measured, not guessed)

**Recommendation:** 8 vCPU / 16 GB RAM / 160 GB+ disk, Ubuntu 24.04, x86 (VoiceStudio and PentAGI
images are amd64). Without VoiceStudio: 4 vCPU / 8 GB / 80 GB is enough.

## How it runs with no operator terminal (no HITL after bootstrap)
- **This cloud session cannot SSH out** (TCP 22 refused, verified 2026-11-09), so the box is driven
  through **Claude Code Remote Control running on the VPS**, not SSH from here. The box then shows up in
  the Claude app; cloud sessions can attach to its folder where that feature is enabled for the account.
- **Bootstrap = two browser-only steps, done once:**
  1. Create the server in the provider's web console and paste our cloud-init into "User data"
     (installs Docker, Git, Node, Claude Code, clones this repo, runs the 5 + 2 setup scripts, enables a
     firewall, starts `claude remote-control` as a service).
  2. Open the provider's web console once and approve the Claude Code login link on your phone.
- After that: installs, sign-ins (OpenBot email code via the Gmail connector), updates, and restarts are
  done by Claude on the box.

## Security baseline
- Inbound firewall: deny all; SSH key-only (or SSH closed, provider web console as break-glass).
- Every service stays bound to 127.0.0.1 (already the default in all 7 scripts). Reach the UIs from your
  phone/laptop over **Tailscale** (free personal plan), never a public port.
- Secrets only in each tool's `.env` (mode 600) on the box; provider keys entered in the tools' dashboards.
- Automatic security updates (`unattended-upgrades`); daily volume backup to provider snapshots.

## Risks / decisions for the operator
- **PentAGI from a rented server:** providers' acceptable-use policies restrict scanning; only test
  targets you own or have written permission for, and check the chosen provider's AUP first.
- **OpenBot is PolyForm Noncommercial:** not for ProdCraft client work without a paid licence.
- **Paid usage on top of the server:** DataForSEO (OpenSEO), model providers (PentAGI, FreeLLMAPI, OpenCode).
- Remote Control as an unattended service is the one unverified piece; verify on the first boot, fallback is
  the provider's web console.
