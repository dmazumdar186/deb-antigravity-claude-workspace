# GreenJobs redesign — source

Static demo of greenjobs.ie + greenjobs.co.uk on a modern stack. One codebase,
two editions (`ie`, `uk`), rendered by a Python build into `../site/`.

## Build

```bash
python3 execution/gtm_client_workflows/greenjobs_redesign/build_site.py            # both editions -> ../site
python3 execution/gtm_client_workflows/greenjobs_redesign/build_site.py --edition ie  # partial (dev only)
python3 execution/gtm_client_workflows/greenjobs_redesign/build_site.py --data-fixture src/data/_fixture.json --out .tmp/gj  # tests
python3 execution/gtm_client_workflows/greenjobs_redesign/build_site.py --today 2026-09-22   # pin the build date (default: the dataset's fetched date)
python3 tests/greenjobs_redesign/run_all.py        # every tier: python (build/validate/scrape/gaps), node --test, Playwright DOM + layout; --allow-skip when Chromium is absent
python3 tests/greenjobs_redesign/test_build.py     # python tier alone
node --test src/js/lib.test.js src/js/dashboard.test.js
bash execution/gtm_client_workflows/greenjobs_redesign/screenshot.sh              # PNGs -> .tmp/greenjobs_redesign_shots
```

The build exits non-zero on any validator failure (relative paths only, every
asset resolves, images dimensioned, JSON-LD parses, one h1, noindex, labelled
controls, no third-party requests, forbidden vocabulary, CSS ≤ 80 KB / JS ≤ 125 KB,
any hero video referenced actually shipped). On success it writes `../site/.greenjobs-build-ok`
(sha256 of the tree); `deploy_cloudflare.sh` refuses to ship without it and re-runs
`validate_site.py <site>` first.

## Layout

- `templates/` — `_shell.html` (head/header/footer) + one template per page. `{{key}}` substitution, values are HTML.
- `css/styles.css` — one stylesheet. Warm-earth tokens at the top (paper, ink, honey, terracotta; sage / sky / clay for data only); `[data-theme="dark"]` overrides. Headlines in Fraunces, text and UI in Nunito, both self-hosted in `assets/fonts/`.
- `js/` — `lib.js` (pure, tested by `lib.test.js` via `node --test`), `main.js` (shared: theme, menu, saved roles, data loading, demo forms, consent-gated `track()` event stub, closed-role state on job pages), `popups.js` (cookie banner + settings, subscribe dialog), `motion.js` (count-ups, reveals, view-transition morph), `landscape.js` (hero scene), `jobs.js` (board), `charts.js` + `explore.js` (sectors, insights), `compass.js` (quiz), `fit.js` (quick job match), `adbuilder.js` (employers preview), `dashboard.js` (KPI charts + CSV, tested by `dashboard.test.js`). Twelve files, nothing else ships from `js/` (`*.test.js` are excluded by the build).
- `data/` — `ie.json`, `uk.json`, `brief.md`, `pages_*.json`, `perf_*.json` (scraped, read-only); `regions_{ie,uk}.json` (region → aliases mapping, edit to improve matching); `_fixture.json` (tests); `clients_{ie,uk}.json` (the client-logo wall from `/for-employers.asp`, `[{name, file, source}]`, files in `assets/logos/clients/`; refresh with `scrape_greenjobs.py --clients-only --assets src/assets/logos`).
- `assets/` — fonts (self-hosted), `maps/{ie,uk}.svg` (generated by `make_maps.py` from Natural Earth), `logos/` (scraped), `favicon.svg`, `hero/` (optional drop-in footage, below).

## Editing

- Copy: edit the template; rebuild. Facts on public pages must come from `data/*.json` or `data/brief.md`.
- Sector taxonomy: `TAXONOMY` in `build_site.py` (name, colour, dark-text flag, keywords).
- Region matching: `data/regions_<ed>.json`; regions must include every `data-region` in the map SVG.
- Home "Why GreenJobs" facts: `BRIEF_FACTS` in `build_site.py`, each traceable to `brief.md`.
- Salary figures on any page: read `salary_stats(jobs, ed)` (count, share, median, bands, disclosed list); never count `sal_min`/`sal_max` by hand, the shared rule excludes unverified-currency and non-comparable roles.
- Job page header ctx keys: `{{closed_chip}}` (a "Closed" chip, `hidden` until the closing date passes) and `{{sal_caveat}}` (the unverified-currency line under the chips, empty otherwise). Imported descriptions pass through `sanitise_html`: bullet lines → `<ul>`, whole-line bold unwrapped, blank runs collapsed.
- Maps: `python3 execution/gtm_client_workflows/greenjobs_redesign/make_maps.py` (downloads Natural Earth 10m admin-1 to `.tmp/` once).

## Hero: canvas landscape, or drop-in footage

The home hero is a procedurally drawn landscape (`js/landscape.js`): hills,
river, solar field, five turbines, hedgerow, clouds, birds, a sun that warms
as you scroll; parallax on scroll and pointer; paused off-screen; one static
frame under reduced motion; a CSS gradient without canvas.

To replace it with generated footage, drop files into `src/assets/hero/` and
rebuild. No code changes:

| File | Purpose |
|---|---|
| `ie.mp4`, `uk.mp4` | Landscape loop, 1280×720 (cut from the 1080p Kling 3.0 Pro source), H.264, no audio track, 8–12 s, ≤ 2 MB per file, ≤ 6 MB for all hero files |
| `ie-m.mp4`, `uk-m.mp4` (optional) | Portrait loop for viewports under 800 px, 1080×1350 crop of the same source, same limits |
| `ie-poster.webp` or `.jpg`, `uk-poster.*` | First frame, shown until the video plays and as the whole hero on Save-Data / reduced motion |

When `<edition>.mp4` exists the build renders a muted, looped, `playsinline`
`<video>` (object-fit cover, warm paper scrim so the copy stays AA) under the
hero content; the canvas landscape plays until the first frame is ready, then
fades out. The video pauses off-screen and under reduced motion. The validator
fails the build if a referenced video or poster is missing from the built site.

## Popups

`popups.js` owns two native dialogs. The cookie banner shows once (essential
storage only; Accept or Settings → Essential / Analytics / Marketing, stored in
`gj-consent`). The subscribe dialog opens once per device 20 s after load or on
exit intent (desktop), never on the jobs / job pages while typing, never within
7 days of a dismissal (`gj-subscribe`). `?popup=cookie|settings|subscribe`
forces a state for captures and tests.

## Deploy

```bash
bash execution/gtm_client_workflows/greenjobs_redesign/deploy_cloudflare.sh  # -> https://greenjobs-redesign.pages.dev/ (needs a fresh .greenjobs-build-ok)
```

The site is served at `/` on Cloudflare Pages. Paths are relative throughout, so it would also serve from a
sub-path; `publish_gh_pages.sh` is retired (exits 2).
Set `config.json` → `site_base` for the sitemap's absolute URLs.
