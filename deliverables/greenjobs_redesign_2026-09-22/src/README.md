# GreenJobs redesign — source

Static demo of greenjobs.ie + greenjobs.co.uk on a modern stack. One codebase,
two editions (`ie`, `uk`), rendered by a Python build into `../site/`.

## Build

```bash
python3 execution/gtm_client_workflows/greenjobs_redesign/build_site.py            # both editions -> ../site
python3 execution/gtm_client_workflows/greenjobs_redesign/build_site.py --edition ie  # partial (dev only)
python3 execution/gtm_client_workflows/greenjobs_redesign/build_site.py --data-fixture src/data/_fixture.json --out .tmp/gj  # tests
python3 tests/greenjobs_redesign/test_build.py
bash execution/gtm_client_workflows/greenjobs_redesign/screenshot.sh              # PNGs -> .tmp/greenjobs_redesign_shots
```

The build exits non-zero on any validator failure (relative paths only, every
asset resolves, images dimensioned, JSON-LD parses, one h1, noindex, labelled
controls, no third-party requests, forbidden vocabulary, CSS/JS ≤ 60 KB).

## Layout

- `templates/` — `_shell.html` (head/header/footer) + one template per page. `{{key}}` substitution, values are HTML.
- `css/styles.css` — one stylesheet. Tokens at the top; `[data-theme="dark"]` overrides.
- `js/` — `lib.js` (pure, tested by `lib.test.js` via `node --test`), `main.js` (shared), `wind.js` (hero), `jobs.js` (board), `charts.js` + `explore.js` (sectors, insights), `compass.js` (quiz).
- `data/` — `ie.json`, `uk.json`, `brief.md`, `pages_*.json`, `perf_*.json` (scraped, read-only); `regions_{ie,uk}.json` (region → aliases mapping, edit to improve matching); `_fixture.json` (tests).
- `assets/` — fonts (self-hosted), `maps/{ie,uk}.svg` (generated by `make_maps.py` from Natural Earth), `logos/` (scraped), `favicon.svg`.

## Editing

- Copy: edit the template; rebuild. Facts on public pages must come from `data/*.json` or `data/brief.md`.
- Sector taxonomy: `TAXONOMY` in `build_site.py` (name, colour, dark-text flag, keywords).
- Region matching: `data/regions_<ed>.json`; regions must include every `data-region` in the map SVG.
- Home "Why GreenJobs" facts: `BRIEF_FACTS` in `build_site.py`, each traceable to `brief.md`.
- Maps: `python3 execution/gtm_client_workflows/greenjobs_redesign/make_maps.py` (downloads Natural Earth 10m admin-1 to `.tmp/` once).

## Deploy

```bash
bash execution/gtm_client_workflows/greenjobs_redesign/publish_gh_pages.sh   # -> gh-pages:/greenjobs/
bash execution/gtm_client_workflows/greenjobs_redesign/deploy_cloudflare.sh  # -> greenjobs-redesign.pages.dev
```

Relative paths throughout, so the same build serves at `/greenjobs/` and at `/`.
Set `config.json` → `site_base` for the sitemap's absolute URLs.
