## 10. Tech stack observed (both homepages, `perf_*.json`)

- Platform: "Job Board website by Strategies" (strategies.co.uk job-board software), shared assets from `https://sjbimg.com/jobboardv3/...` (`JobboardGlobal.js`, `bootstrap.min.js`), classic ASP (`.asp` URLs, `/jobboard/cands/*.asp`), build tag `?bn=3.1.3`.
- jQuery 1.11.0 from ajax.googleapis.com; Bootstrap 3 JS/CSS (`col-sm-*` grid); `html5shiv.min.js` and `respond.min.js` (IE8 shims); `Sizzle.js`, `Getme-1.0.4.js`, `ClientValidator.js`, `autoComp.js`, `AutoCompleteSearch.js`; separate `ie.css`, `ie7.css`, `ie8.css`, `ieLegacy.css` conditional stylesheets; GA4 `G-ZQPJGM484J` (IE) / `G-ZFW03XQE2N` (UK) via gtag.
- Job detail page comment: "Invalid salary data, so Google Schema is disabled for this site" — no JobPosting structured data is emitted.
- Cookie banner text is duplicated twice in the DOM.

## 11. Measured UX weaknesses (numbers measured 2026-09-22)

- Homepage HTML alone: **190.0 KB** (IE, 189,996 B) and **135.8 KB** (UK). 16 external `<script>` tags + 6 inline script blocks, 3 stylesheets, 65 (IE) / 79 (UK) `<img>` tags; estimated **44 (IE) / 59 (UK) requests** for first paint.
- Measured transfer of the 15 scripts + 3 stylesheets + 4 key images on IE: **1,058,725 B (~1.03 MB)** before fonts and the remaining images. Largest: `site.min.js` 221 KB, `main.css` 168 KB, `responsive-style.css` 132 KB, jQuery 96 KB, `JobboardGlobal.js` 91 KB, hero JPG 77 KB, 468x60 banner PNG 48 KB, `ClientValidator.js` 44 KB, `print.css` 28 KB (render-blocking with no media attribute).
- Link density: **1,090 anchors** on the IE homepage (441 `/browse-jobs/` links; 214 sector + 211 category lists rendered in full, most with "(0)" counts) — 664 on UK.
- Salary disclosure: only 29/88 IE jobs (33%) and 56/98 UK jobs (57%) show a numeric salary; the rest say "Competitive Salary Offered" or similar.
- Broken link: UK footer B Corp logo → 404. IE `/talent-finder-network.cms.asp` and `/job-distribution-partners.cms.asp` bodies are 21–25 characters of text (effectively empty). `/company-az/` on IE lists only 3 recruiters (Commonland 2, Gaia Talent 63, Mattinson Partnership 23).
- Results pages paginate at 10 (IE) / 15 (UK) per page with a checkbox "View Selected / Add To Wish List" pattern and desktop-only "Details/Apply" buttons; job listing dates are dd/mm/yyyy strings, no relative dates.
- Mobile: viewport meta present and Bootstrap 3 grid, but the sector/category tabs ("Show / Hide" toggles) load all ~425 links regardless; IE7/IE8 CSS and html5shiv still shipped to every browser. No measurement of Lighthouse scores was possible in this environment (no headless browser).
