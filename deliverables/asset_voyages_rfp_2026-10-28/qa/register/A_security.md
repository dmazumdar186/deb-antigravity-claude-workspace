## Production key note (for the README check)

Weak by design in the demo: with no `ASSET_GME_KEY`, the key is `generichash(wp_salt('auth') . '|asset-gme-v1')`. When wp-config does not define the salts, WordPress keeps them in `wp_options`, so **a database dump or backup alone decrypts every code** (proved in ADV-A-001). Production must: define `ASSET_GME_KEY` from an environment variable or secret manager, never in the DB; **fail closed** (refuse to save or reveal, and show an admin notice) when the constant is missing or malformed instead of falling back silently; bind ciphertext to `congres_id` (secretbox over `id|code`, or AEAD with AAD); keep an offline escrow copy and a rotation command.
