Le statut éditorial (brouillon → en validation → publié, retour au brouillon sans perte) est séparé du workflow interne (détecté → vérifié → dossier GM&E à préparer → demande déposée → code reçu → émission autorisée → approuvé pour la vente → archivé). Seul le statut « publié » a un effet public ; le workflow n'apparaît jamais sur le site.
