# Quick start: the 3 things you will do most

(Version française en dessous.) Full manual: **README.md** (English) or **LISEZMOI.md** (français).

**Before anything:** open https://app.pagescms.org → **Sign in with GitHub** → click the project **yogaavecjitendra**.
The menu on the left (with **Media**) only appears after you click the project.
If you do not see the project, the setup is not finished yet.

## 1. Change a photo

1. Left menu → **Media** → folder **images** → **Upload** → choose the photo (JPG, under 1 MB).
2. Left menu → click the page:
   - big photo at the top or your portrait → **Home page (French)**, boxes **Big photo at the top** / **Your portrait photo**
   - photo of a class → **Offerings / classes (French)** → **Tiles** → open the class → **Image** (or **Images**)
   - photos that slide → **Schedule & prices (French)** → **Gallery**
3. Click the photo box → choose your new photo. Write one line about it in the description box under it.
4. Click **Save**. The website changes in about 3 minutes.
5. Do the same on the **(English)** page.

In a list (**Gallery**, **Images**): **Add an item** adds a row, the trash icon removes it, drag a row to move it.

## 2. Background music: on, off, change, volume

Left menu → **Ambient sound (site settings)**:
- **Play ambient music**: ticked = music, not ticked = silence.
- **Music file (MP3)**: choose a track. Two flute tracks are already there. A new track: **Media** → **audio** → **Upload** (free-to-use music only).
- **Volume (0 to 1)**: 0.2 soft, 0.5 medium (today), 1 loudest.

Click **Save**.

## 3. Add a review

Left menu → **Reviews (stars and comments)** → **Add an item** → fill **Name of the person**, **Stars (1 to 5)**, **Review text**, **Date of the review** → **Save**.

Made a mistake? Open the page again, click the **clock icon** (top right) and go back to an earlier version.

# Démarrage rapide : les 3 choses que vous ferez le plus

**Avant tout :** ouvrez https://app.pagescms.org → **Sign in with GitHub** → cliquez sur le projet **yogaavecjitendra**.
Le menu de gauche (avec **Media**) n'apparaît qu'après avoir cliqué sur le projet.
Si vous ne voyez pas le projet, l'installation n'est pas encore terminée.

## 1. Changer une photo

1. Menu de gauche → **Media** → dossier **images** → **Upload** → choisissez la photo (JPG, moins de 1 Mo).
2. Menu de gauche → cliquez sur la page :
   - grande photo en haut ou votre portrait → **Home page (French)**, cases **Big photo at the top** / **Your portrait photo**
   - photo d'un cours → **Offerings / classes (French)** → **Tiles** → ouvrez le cours → **Image** (ou **Images**)
   - photos qui défilent → **Schedule & prices (French)** → **Gallery**
3. Cliquez sur la case photo → choisissez la nouvelle photo. Écrivez une ligne qui la décrit dans la case de description en dessous.
4. Cliquez sur **Save**. Le site change en 3 minutes environ.
5. Faites la même chose sur la page **(English)**.

Dans une liste (**Gallery**, **Images**) : **Add an item** ajoute une ligne, la corbeille la supprime, faites glisser une ligne pour la déplacer.

## 2. Musique de fond : marche, arrêt, changer, volume

Menu de gauche → **Ambient sound (site settings)** :
- **Play ambient music** : coché = musique, décoché = silence.
- **Music file (MP3)** : choisissez une musique. Deux morceaux de flûte sont déjà là. Nouvelle musique : **Media** → **audio** → **Upload** (musique libre de droits uniquement).
- **Volume (0 to 1)** : 0.2 doux, 0.5 moyen (aujourd'hui), 1 le plus fort.

Cliquez sur **Save**.

## 3. Ajouter un avis

Menu de gauche → **Reviews (stars and comments)** → **Add an item** → remplissez **Name of the person**, **Stars (1 to 5)**, **Review text**, **Date of the review** → **Save**.

Une erreur ? Rouvrez la page, cliquez sur l'**icône horloge** (en haut à droite) et revenez à une version précédente.
