# yoga_jitendra_site

Personal website for Jitendra Kumar, Paris-based Hatha Yoga teacher. Replaces his
Google Sites placeholder at `sites.google.com/view/yogaavecjitendra/home`.
Astro static site + Cloudflare Pages (free tier).

## Goal

Ship a peaceful, traditionally-flavoured, mobile-first bilingual (FR/EN)
marketing site for Jitendra that:

- puts his real photos + real testimonials + press mention front and centre,
- honours the Indian yoga lineage (Sanskrit shloka + Ashtanga + rishi/muni
  framing),
- provides a WhatsApp-first booking path (no calendar for v1, per operator),
- feels traditional, not gym-y — through palette (cream / terracotta / sage),
  typography (Fraunces + Inter + Noto Serif Devanagari), a looped ambient
  audio track (a LICENSED Pixabay bansuri recording — see "Ambient audio"
  under Steps; synthesis is retired), and an inline-SVG mandala backdrop
  generated by GLM 5.2.

## Inputs

- `_raw_assets/` — 24 candidate files supplied by operator (17 photos + 7 review
  screenshots). **This directory is gitignored** to keep third-party faces
  outside git history.
- Site content in `src/content/*.{fr,en}.json` — every visible string, both
  languages.
- Design brief in `design_brief.md` (fed into GLM 5.2 prompts) and in
  `~/.claude/plans/https-sites-google-com-view-yogaavecjite-synthetic-sunrise.md`
  (the approved plan).

## Tools / scripts

- Astro 5 + Tailwind + Motion One — build framework (`npm run dev`, `npm run build`).
- **GLM 5.2 via `execution/modules/model_router.call_model('glm', ...,
  sensitivity="public")`** — generates the creative HeroBackdrop.astro (inline
  SVG mandala + CSS animations, ~7.5 KB). Prompt engineering + hard-cap 2 rounds
  per slice live in `generate.py`. Per `~/.claude/rules/model-tier.md` Exhibit
  C, no PII / testimonial names / phone / email is ever sent to GLM.
- Cloudflare Pages via `npx wrangler pages deploy dist/` (matches
  `portfolio_site` deploy pattern).
- **`scripts/generate_ambient_loop.py`** — HISTORICAL ONLY (retired
  2026-09-01 pm after the client rejected all four synthesized iterations).
  Do NOT run it and do NOT wire its output; the live ambient track is a
  licensed recording. See "Ambient audio" under Steps.
- **`scripts/backfill_review_dates_from_maps.mjs`** — one-off Node script
  that corrects `submitted_at` on reviews KV records against Google Maps
  ground truth. Dry-run by default; `--apply` mutates prod KV via wrangler.
  See "Review-date backfill" under Edge cases.
- Tests: `tests/acceptance_yoga_jitendra.py` (hard-fail output-acceptance gate)
  + `tests/front_door_yoga_jitendra.sh` (live URL front-door synthetic).

## Steps

1. `npm run build` — Astro builds `dist/index.html` and copies `public/assets/`
   images and inlined CSS.
2. `py tests/acceptance_yoga_jitendra.py` — must exit 0.
3. `npx wrangler pages deploy dist/ --project-name=yoga-jitendra --branch=main` —
   uploads incremental delta to CF Pages CDN.
4. `bash tests/front_door_yoga_jitendra.sh https://yoga-jitendra.pages.dev` —
   asserts live artifact contract holds. Must exit 0.
5. Only after 5 consecutive daily green runs on step 4 may any report describe
   the site as "shipped / live / ready" per
   `~/.claude/rules/front-door-synthetic.md`.

### Ambient audio (licensed recording — synthesis retired 2026-09-01 pm)

The live ambient track is a LICENSED Pixabay recording, not generated
audio. Four synthesized iterations (`birds-dawn`, `himalayan-chant`,
`serene-dawn`, `bansuri-dawn`) were each rejected by the client on
auditory grounds; the last verdict ("breath breaking every 2 seconds")
ended the synthesis approach. `scripts/generate_ambient_loop.py` is kept
as a historical record only — running it is harmless (it writes an
unreferenced file) but wiring its output back into `Base.astro` would
regress the client-approved direction.

- **Primary (wired)**: `public/assets/audio/bansuri-studio.mp3` =
  "bansuri flute" by PoshPony, Pixabay id 406082, human-performed, 4:00.
  https://pixabay.com/music/world-bansuri-flute-406082/
- **Alternate (deployed, not wired)**: `public/assets/audio/bansuri-raga-alt.mp3`
  = "Indian Bansuri Flute Tarana Raga Music" by boopul, Pixabay id 525950,
  **AI-generated** (disclose this if offered to the client), 7:59.
  https://pixabay.com/music/meditationspiritual-indian-bansuri-flute-tarana-raga-music-525950/
- **A/B switch**: append `?audio=alt` to any public page URL to hear the
  alternate in page context (handled in `Base.astro`'s inline audio script).
- **License**: Pixabay Content License — free for commercial use on client
  sites, no attribution required, but standalone redistribution of the bare
  file is outside the license, so don't advertise the raw mp3 URLs as
  downloads. Local evidence snapshots live in
  `execution/personal_workflows/yoga_jitendra_site/licenses/`.
- **Processing recipe** (if the source track ever needs re-preparing): PyAV
  decode → 2 s fade-in + 3 s fade-out (softens the `<audio loop>` seam,
  which is NOT gapless for MP3 in browsers) → peak-normalize to -1 dBFS →
  re-encode 112 kbps 44.1 kHz stereo. Script pattern in the 2026-09-01
  session scratchpad; ~3.4 MB output for a 4:00 track.
- To swap primary ↔ alternate permanently: change the `src` in
  `src/layouts/Base.astro`'s `<audio id="om-audio">` element AND the pinned
  filename in `tests/front_door_yoga_jitendra.sh` +
  `tests/acceptance_yoga_jitendra.py`, then build + deploy.

## Edge cases

- **Autoplay policy.** Every browser blocks `<audio>` autoplay-with-sound.
  Site works around by resuming `AudioContext` on first user gesture
  (`mousemove` + click + touch + scroll + keydown). Fresh visitor hears
  silence until they move their cursor — practically ~500 ms after load.
- **`prefers-reduced-motion`.** All animations (mandala rotation, breath
  keyframes, hero-headline word reveal, gallery hover) degrade cleanly when
  the OS accessibility setting is on. The ambient audio loop is unaffected —
  it's audio, not motion — and stays gated behind the autoplay-policy
  first-gesture unlock above.
- **Group-session photos.** Curation avoids close-up faces of attendees
  without documented consent. If operator later warrants consent for wider
  usage, we can broaden the curation set (see `_raw_assets/`).
- **Sanskrit rendering.** Uses Google Font `Noto Serif Devanagari`. If font
  fails to load, `Fraunces` falls back — Devanagari glyphs will still render
  via the OS's native fallback fonts on macOS / iOS / Android; on Windows
  without any Devanagari font the shloka may render as boxes. This is a
  known browser limitation, not a site bug.
- **Cost cap.** GLM 5.2 slices hard-capped at 2 rounds × 3 slices × ~€0.03 =
  **~€0.20 max per full regeneration**. If OpenRouter balance is $0, the
  script falls back to Anthropic Sonnet 4.6 (~€0.30/round) — documented in
  `generate.py`.
- **Testimonial names + phone/email/address.** Kept in local
  `content/*.{fr,en}.json` files. **Never sent to GLM 5.2.** Substituted at
  Astro build time only.
- **Custom domain.** Deferred. When Jitendra buys a domain, bind in the CF
  Pages dashboard (Settings → Custom domains). No code change needed.
- **Review-date backfill.** Two related date bugs in the reviews KV
  (`submitted_at` silently stamped to `now()` when the moderation UI's
  "Submitted at" field was left blank, plus 3 records with a manually
  entered but wrong date) were corrected against Google Maps ground truth
  via `backfill_review_dates_from_maps.mjs`. **Applied to prod KV on
  2026-09-01**: Virginie → 2026-07-14; Atlasia, Sejal, Sakshi →
  2026-07-11. The script is idempotent (re-running is a no-op once a
  record carries `date_backfill_source: "google_maps_scrape_2026-08-04"`)
  and only ever touches records the intermediate JSON marks
  `UPDATE`/`UPDATE_FROM_SEED` — see the script's header comment for the
  rollback path.
- **Windows arg-quoting in wrangler shell-outs.** Any script that spawns
  `wrangler` via `child_process.spawn(..., { shell: true })` on Windows
  must quote args containing whitespace — this workspace's path
  ("AntiGravity Project Space") otherwise splits into multiple argv
  entries and wrangler dies with "Unknown argument". Fixed in
  `backfill_review_dates_from_maps.mjs`; the same fix is owed on any other
  script in this project that shells out to wrangler the same way.

## Exit criteria

The project is only describable as "shipped / live / ready" once ALL of the
following hold:

1. `py tests/acceptance_yoga_jitendra.py` exits `0` — 43+ assertions green.
2. `bash tests/front_door_yoga_jitendra.sh` exits `0` against
   `https://yoga-jitendra.pages.dev` — 24+ live assertions green.
3. Steps 1-2 have both passed for **5 consecutive daily runs** (per
   `~/.claude/rules/front-door-synthetic.md`). Until day 5 the site status is
   `LIVE-PROBATIONARY: day N of 5`.
4. Jitendra has personally reviewed the FR + EN copy (proxy PM = operator).
5. RGPD / droit-à-l'image warranty from operator on any group photo showing
   identifiable non-Jitendra faces.
6. Lighthouse mobile audit: Performance ≥85, Accessibility ≥95, LCP <2.5 s.

Any FAIL on 1-3 blocks the "live" claim. Skip on 4-6 is allowed but must be
logged in the wrap-up.
