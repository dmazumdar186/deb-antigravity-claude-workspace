Thank you for yesterday. You pushed on two points, and you were right to.

First, the cleaned values. They do a different job from the two new date filters. The date filters answer "is this still true?". The cleaned columns answer "is this written the same way?", for example eight spellings of London. Admins should see the second, and the deck already needs a screen for it, since each school can override the shared clean-up lists. Here is how it looks, using the 49 members from the case file:

https://trusted-segments-concept.pages.dev

It is clickable. "Visite" runs a seven-step tour, and the pins explain each element. Three rules keep it light for admins:
- What the member typed stays visible (on hover in the prototype) and is never changed.
- Uncertain clean-ups are marked "suggested" until an admin confirms them.
- Admins review only those exceptions, sorted by members affected. AlumnForce maintains the shared lists.
